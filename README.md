# notes

アップシフト合同会社の「会議のまとめ」公開用の置き場です（GitHub Pages）。

- 各議事録は `m/<番号>/` に置き、本文とPDFは暗号化（AES-GCM）してあります。鍵はこの置き場には保存しません。
- 見る人には `https://upshift-jp.github.io/notes/m/<番号>/#k=<鍵>` の形のリンクを送ります。
- 作り方：`python3 tools/make_note.py <議事録.html> <議事録.pdf> m/<番号> "<宿題コピーの見出し>" "<PDFのファイル名>" "<保存キー>"`（最後に鍵を表示）
- フォルダ名に会社名・人名は入れないこと。
